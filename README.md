# ISO/IEC 27001 Risk Assessment Project

## Overview

This project demonstrates the implementation of an ISO/IEC 27001:2022 information security risk assessment for a fictional small organization. It was developed as a portfolio project to demonstrate practical knowledge of information security risk management, risk assessment methodologies, and ISO/IEC 27001 documentation.

The project follows a structured approach to identifying information assets, assessing risks, selecting appropriate security controls, and developing risk treatment plans.

---

## Project Objectives

- Identify information assets
- Assess information security risks
- Evaluate risk likelihood and impact
- Recommend appropriate risk treatment actions
- Demonstrate the ISO/IEC 27001 risk assessment process

---

## Standards and Frameworks

- ISO/IEC 27001:2022
- ISO/IEC 27005
- ISO 31000
- CIS Critical Security Controls v8 (Reference)

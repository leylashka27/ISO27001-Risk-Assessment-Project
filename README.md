# ISO/IEC 27001:2022 Information Security Risk Assessment Project

## Overview

This project demonstrates the practical implementation of an information security risk assessment process in accordance with ISO/IEC 27001:2022. It was developed as a portfolio project to demonstrate practical knowledge of information security risk management, risk assessment methodologies, and ISMS documentation.

The project follows a structured approach to identifying information assets, assessing information security risks, selecting appropriate risk treatment measures, and documenting applicable security controls.
---

## Project Objectives

-The objective of this project is to demonstrate the practical application of information security risk assessment principles based on ISO/IEC 27001:2022.

The project aims to:

Identify and classify information assets.
Identify information security threats affecting organizational assets.
Assess information security risks using a qualitative risk assessment methodology.
Evaluate risk likelihood and business impact.
Develop a Risk Treatment Plan.
Select applicable security controls based on ISO/IEC 27001:2022 Annex A.
Prepare supporting ISMS documentation.

## Project Documents

The project consists of the following documentation.

### Microsoft Excel Documents

- **01_Asset_Inventory.xlsx** – Inventory of organizational information assets.
- **02_Threat_Register.xlsx** – Identified threats associated with information assets.
- **03_Risk_Assessment.xlsx** – Risk analysis including likelihood, impact, and risk level.
- **04_Risk_Treatment_Plan.xlsx** – Selected risk treatment strategies and implementation actions.
- **05_Statement_of_Applicability.xlsx** – Applicable ISO/IEC 27001:2022 Annex A controls and implementation justification.

### Microsoft Word Documents

- **06_Information_Security_Policy.docx** – Information security policy defining the organization's security objectives and principles.
- **07_ISMS_Scope.docx** – Scope and boundaries of the Information Security Management System.
- **08_Risk_Assessment_Methodology.docx** – Methodology used to identify, analyze, evaluate, and treat information security risks.
- **09_Risk_Assessment_Report.docx** – Summary of the completed risk assessment and risk treatment activities.
